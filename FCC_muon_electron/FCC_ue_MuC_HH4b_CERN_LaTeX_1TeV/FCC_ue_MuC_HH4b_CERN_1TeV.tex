\sectionlabel{Fiducial selection}
\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=1pt,parsep=0pt]
\item All four final-state $b/\bar b$   partons   satisfy   $|\eta_b|<5$.
\item Form two \emph{disjoint}, opposite-charge $b\bar b$ pairs. Accept the event if either distinct pairing has \emph{both} masses in $110\le m_{b\bar b}^{(1,2)}\le130\,\mathrm{GeV}$; count each event once.
\item \textbf{No minimum $p_T$ cut} is applied (in particular, the optional $5\,\mathrm{GeV}$ threshold is \emph{not} used).  
\item  These are parton-level estimates (no showering, jet clustering, tagging or detector simulation). 
\end{itemize}
