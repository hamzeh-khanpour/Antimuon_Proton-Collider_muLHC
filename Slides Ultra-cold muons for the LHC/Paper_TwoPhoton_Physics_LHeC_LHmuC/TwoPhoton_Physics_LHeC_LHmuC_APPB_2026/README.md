## Important publication-format caveat

The *Acta Physica Polonica B* journal website confirms that authors are encouraged to use its official `appolb.cls`. However, the original class file **could not be downloaded to this computing environment**; rather than package a fabricated class or misstate compliance, the source uses a portable 11-point `article` class with journal-proportioned A4 typography. This is a professional, self-contained preview, **not yet certified as using the publisher's class**. Before submission, download the current class and template from https://www.actaphys.uj.edu.pl/for_authors and migrate the final manuscript, checking length and typography afresh. The eight-page target is verified for this portable layout only.

## Compile

Required: TeX Live `pdflatex`, standard LaTeX packages (`amsmath`, `amssymb`, `lmodern`, `microtype`, `graphicx`, `booktabs`, `hyperref`, `xcolor`, `geometry`) and BibTeX.

Run:

```bash
bash build.sh
```

Or run the commands manually:

```bash
pdflatex -interaction=nonstopmode -halt-on-error TwoPhoton_Physics_LHeC_LHmuC.tex
bibtex TwoPhoton_Physics_LHeC_LHmuC
pdflatex -interaction=nonstopmode -halt-on-error TwoPhoton_Physics_LHeC_LHmuC.tex
pdflatex -interaction=nonstopmode -halt-on-error TwoPhoton_Physics_LHeC_LHmuC.tex
pdfinfo TwoPhoton_Physics_LHeC_LHmuC.pdf | grep Pages
```

Some TeX Live installations have a broken `/usr/bin/bibtex` alternative but a functional `/usr/bin/bibtex.original`, which the `build.sh` script detects. This package includes a generated `.bbl` only transiently during compilation; all BibTeX sources are present.

To regenerate the vector figures (optional), run:

```bash
python3 -m pip install numpy scipy matplotlib
python3 make_figures.py
```

The LaTeX source references only relative `figures/` paths; Python is **not** needed to compile the provided vector graphics.

1. Prior source files `yy_lhec.pdf`, `draft_yy_lhec.pdf`, `Hamzeh_Khanpour_a_tau_LHeC_LHmuC.pdf` and the workshop figure ZIP were indexed in the project, but their raw bytes could not be recovered during this build. Numerical cross sections quoted from the preceding discussion are **indicative** until cross-checked against the original exact selections.
2. Original anomalous-tau and aQGC numerical curves are therefore **not recreated or relabelled**; the paper discusses their physics conservatively rather than inventing limits or plot shapes.
3. The full arXiv:2610.35154 PDF was not accessible to the current tool environment; its author/title/energies/luminosity were checked against the arXiv metadata/abstract only.
4. All collider energy assumptions, simulated cuts, integrated-luminosity conventions, statistical projections, acknowledgements, and any collaborative authorship must be checked by the actual author before public release.
5. The illustrative numerical EPA luminosity plot is independently computed with `Q^2_{l,max}=10 GeV^2` and the Drees--Zeppenfeld elastic proton approximation; it **must not be substituted** for the source-analysis plots without explaining the differences.
